Для работы необходимо выбрать вид объекта и набор полей.
Вид можно выбрать из девого окна списка, при этом поля, ему принадлежащие, откроются в правом списке.
Если выбор делать из основного меню, то кроме открыттия полей будет проиведено выделение нужных полей в общем списке.
С нажатой клавишей Ctrl можно добавить интересующие поля.
Клавиши F1, F2 переключают содержимое списков на их русское или латинское название. Клавиша F3 делает выделени нужных полей.
При этом в нижней строке производится создание команды для запроса к базе данных, которую можно дополнить самостоятельно.
После выбора таблицы и полей можо сделать выборку по составленному заапросу, либо по кадастровым номерам,которые должны
находиться в буфере обмена.
После успешной выборки делается Определение кодов НП либо по вабранному виду, либо по всем видам сразу, 
после чего можно запустить программу на получение информации для занесения изменений в базу.
Правила можно запустить предварительно выбрав вид объекта (пока только земельные участки). Правила работают на основе 
данных имеющихся в параметрах. При заполнени правил используется выпадающее по правой клавише меню. В конце редактирования
правил рекомендуется произвести проверку.

Для создания связанных таблиц создается шаблон на результатах запроса. Шаблон должен иметь следующие строки:
1 строка - названия полей по русски (названия можно редактировать)

2 строка - названия полей по латински согласно названиям полей в таблицах ZIS.

3 строка - дополнительная, создается пользователем и содержит названия таблиц, к которым относятся поля строки 2. 
Строка создается простым заполнением ячеек названиями одной или нескольких таблиц.

4 строка создается так же как и 3, в ней ставится признак замены кода на значение. Признак, это любое отличное
от пустрой строки значение, например слово "справочник" или "spr". Если признак есть, то, к примеру, 
код "Вид объекта недвижимости" 2001003000 заменится словом "Помещение", взятым из классификатора. 
Поля, в которых имеются коды, находятся в файле CodeNP.ini в секции Klassificator и добавляются по мере 
необходимости в одну строку через запятую. Каждое поле должно содержать ID Классификатора отделенное от названия двоеточием.
Важно! Строка  должна иметь заливку желтого цвета, в дальнейшем она будет удалена, но по ней определяются данные,
которые будут извлечены из таблиц. Все столбцы, имеющие отличный от желтого цвет будт копироваться как формулы.

5 строка - любая запись из базы, содержащая формулы расчета. В дальнейшем из строки потребуются только формулы.
	
6 строка, колонка A - это ячейка со строкой запроса к базе по которой производится выборка и фильтрация записей.
Запрос должен состоять из 1 строки!!!

Примечание. В случае сложного запроса, содержащего строку длиной > 32767 символов Excel переносит её в нижние ячейки.
